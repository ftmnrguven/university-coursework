# Data Structures

This folder contains coursework, exercises, and implementations related to fundamental data structures.

## Topics

- Arrays
- Linked lists
- Stacks
- Queues
- Trees
- Searching and traversal techniques
- Data structure implementation and practice

## Purpose

The materials in this folder were created as part of my university coursework and practice while studying data structures.

They document my progress in understanding how different data structures work, how they are implemented, and how they are used to solve programming problems.
